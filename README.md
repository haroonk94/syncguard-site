# syncguard-site

Static site for SyncGuard, a Shopify app operated by Infraexcel Private Limited,
Lahore, Pakistan (infraexcel@hotmail.com).

Pages:

- `index.html` — what SyncGuard does
- `privacy.html` — privacy policy
- `terms.html` — end user licence agreement
- `disconnect.html` — how to disconnect the app
- `reconnect.html` — how to reconnect the app

Served via GitHub Pages from the `main` branch.
